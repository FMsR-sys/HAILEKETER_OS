# HAILEKETER_OS
## 简介
 使用NASM汇编与C++一个基于x86架构的自研操作系统

## 开发相关
### ✨已实现功能

 ✅ Bootloader 完成：A20、GDT、E820 探测、磁盘读取、跳转内核
 
 ✅ C++ 内核基础：BSS 清零、基础 VGA 字符输出

### 📝计划
  1.完善终端子系统

  2.硬件驱动

  3.中断与异常体系

  4.内存管理（PMM，VMM，PAE）

  5.任务与调度

  6.用户态支持

  7.FAT32 文件系统，从磁盘读取程序文件
  
  8.简单 shell 交互，用户可以输入命令
  
  9.简单堆溢出、内存保护相关调试工具

## 🛠编译与运行
工具链：i686‑elf‑gcc、nasm、qemu‑system‑i386，VScode
