# HAILEKETER_OS

使用NASM汇编与C++开发的、基于x86‑32架构的自研操作系统。

## 开发相关

### ✨ 已实现功能
- **Bootloader**: A20开启、GDT加载、E820内存探测、磁盘读取、跳转C++内核
- **C++内核基础**: BSS段清零
- **VGA文本终端**
  - 清屏、自定义文字颜色
  - 单字符打印、字符串输出
  - 自动换行、满屏画面向上滚动一行
  - 修复多行一次性溢出丢失内容问题
  - 输出16进制字符
- **内存分页**
  - 构建完整页目录与1024张页表
  - 0‑4GB全地址恒等映射：虚拟地址 = 物理地址
  - 成功开启CR0分页位，流水线刷新正常
- **中断基础框架**
  - 端口IO、PIC、ISR基础实现
- **PMM位图物理内存管理器**
  - 支持使用和释放内存
  - 支持借用E820标记空闲内存
  - 支持自动标记

## 📝 开发计划
1. 完善终端子系统（PS/2键盘输入、可交互控制台）
2. 硬件驱动（键盘等）
3. 中断与异常体系（IDT、PIC）
4. 内存管理（VMM虚拟内存、PAE扩展）
5. 进程与任务调度
6. 用户态支持
7. FAT32 文件系统，从磁盘读取程序文件
8. 简单 Shell 交互，支持命令输入
9. 调试工具，内存保护检测

## ⚒️ 编译与运行
- 编译工具链：`i686‑elf‑g++`、NASM
- 虚拟机测试：`qemu‑system‑i386`
- 开发环境：VSCode + MSYS2
