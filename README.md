# HAILEKETER_OS

使用 NASM 汇编与 C++ 开发的、基于 x86‑32 架构的自研操作系统。

## 开发相关

### ✨ 已实现功能

- **Bootloader**: A20 开启、GDT 加载、E820 内存探测、磁盘读取、跳转 C++ 内核
- **C++ 内核基础**: BSS 段清零
- **VGA 文本终端**
  - 清屏、自定义文字颜色
  - 单字符打印、字符串输出
  - 自动换行、满屏画面向上滚动一行
  - 修复多行一次性溢出丢失内容问题
  - 输出 16 进制字符
  - 硬件光标控制，边界保护
  - 退格删除字符，跨行退格支持
- **内存分页**
  - 构建完整页目录与 1024 张页表
  - 0‑4GB 全地址恒等映射：虚拟地址 = 物理地址
  - 成功开启 CR0 分页位，流水线刷新正常
- **中断基础框架**
  - 端口 IO 封装重制
  - PIC 8259 中断重映射、EOI 发送
  - IDT 中断描述符表、ISR 中断服务例程完整框架
- **PMM 位图物理内存管理器**
  - 物理页分配与释放
  - 读取 E820 内存地图标记可用空闲内存
  - 自动标记内核占用内存区域，防止内核被覆盖
- **PS/2 键盘驱动 & 交互式控制台**
  - IRQ‑1 键盘中断，扫描码读取解析
  - QWERTY 字母输入、左右 Shift 大小写切换
  - 回车键换行、退格删除
  - 0xE0 扩展扫描码支持：方向键 ↑ ↓ ← → 移动光标
  - 按键防抖，屏蔽长按刷屏

## 📝 开发计划

1. 内存管理（VMM 虚拟内存管理器、二级页表管理、PAE 扩展）
2. CPU 异常处理、中断体系完善
3. 进程与任务调度
4. 用户态特权级支持
5. FAT32 文件系统，从磁盘读取程序文件
6. 交互式 Shell，支持命令输入执行
7. 调试工具、内存越界保护检测

## ⚒️ 编译与运行

- 编译工具链：`i686‑elf‑g++`、NASM
- 虚拟机测试：`qemu‑system‑i386`
- 开发环境：VSCode + MSYS2
