# HAILEKETER_OS

使用 NASM 汇编与 C++ 开发的、基于 x86‑32 架构的自研操作系统。

## ✨ 已实现功能

- **Bootloader**: A20 开启、GDT 加载、E820 内存探测、磁盘读取、跳转 C++ 内核
- **C++ 内核基础**: BSS 段清零
- **VGA 文本终端**
  - 清屏、自定义文字颜色
  - 单字符打印、字符串输出
  - 自动换行、满屏画面向上滚动一行
  - 修复多行一次性溢出丢失内容问题
  - 输出 16 进制字符
  - 硬件光标控制，边界保护
  - 退格删除字符，跨行退格支持
  - **120 行后台缓冲区，支持 PageUp/PageDown 翻阅历史日志**
- **内存分页**
  - 构建完整页目录与 1024 张页表
  - 0‑4GB 全地址恒等映射：虚拟地址 = 物理地址
  - 成功开启 CR0 分页位，流水线刷新正常
- **中断基础框架**
  - 端口 IO 封装重制
  - PIC 8259 中断重映射、EOI 发送
  - IDT 中断描述符表、ISR 中断服务例程完整框架
- **PMM 位图物理内存管理器**
  - 物理页分配与释放
  - 读取 E820 内存地图标记可用空闲内存
  - 自动标记内核占用内存区域，防止内核被覆盖
- **内核堆分配器**
  - `kmalloc` / `kfree` 动态内存接口
  - 双向空闲块合并，减少内存碎片
  - 基础重复释放检测
- **PS/2 键盘驱动 & 交互式控制台**
  - IRQ‑1 键盘中断，扫描码读取解析
  - QWERTY 字母输入、左右 Shift 大小写切换
  - 回车键换行、退格删除
  - 0xE0 扩展扫描码支持：方向键 ↑ ↓ ← →
  - PageUp / PageDown 翻阅终端历史输出
  - 按键防抖，屏蔽长按刷屏

## 📝 开发计划

1. 交互式内核 Shell，命令解析与内置指令
2. VMM 虚拟内存管理器、二级页表管理、PAE 扩展
3. CPU 异常处理、完善中断体系
4. 进程与任务调度
5. 用户态特权级支持
6. FAT32 文件系统，支持从磁盘加载程序
7. 调试工具、内存越界保护检测

## ⚒️ 编译与运行

- 交叉工具链：`i686-elf-g++`、NASM
- 模拟器：`qemu-system-i386`
- 开发环境：VSCode + MSYS2
